# React Three Fiber (R3F) 3D Visuals Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement React Three Fiber (`@react-three/fiber`) across Sourced on branch `prototype/r3f-3d-visuals` with an interactive Hero Radar Signal Sphere, detail-page 3D Solution Graph, and lightweight CSS 3D card tilt & sheen without compromising Core Web Vitals or mobile battery.

**Architecture:** Client-only dynamic loading (`next/dynamic` with `ssr: false`), viewport-gated rendering via `IntersectionObserver`, clamped DPR `[1, 1.5]`, and hardware-accelerated CSS 3D for grid cards.

**Tech Stack:** Next.js 14, React 18.3.1, Three.js (`three`), `@react-three/fiber@8`, `@react-three/drei@9`, TypeScript, Vitest.

**Spec:** [docs/superpowers/specs/2026-09-08-r3f-3d-visuals-design.md](file:///c:/Users/falcon/Downloads/sourced-nextjs/docs/superpowers/specs/2026-09-08-r3f-3d-visuals-design.md)

## Global Constraints
- React version is 18.3.1; use `@react-three/fiber` v8 and `@react-three/drei` v9 for 100% React 18 compatibility.
- Never push to `main` — all work stays on `prototype/r3f-3d-visuals`.
- No WebGL canvases on the server; all R3F canvases must be `'use client'` and dynamically imported with `ssr: false`.
- Respect `@media (prefers-reduced-motion: reduce)` with zero-rAF fallbacks.
- Existing Vitest test suites (47 test files, 228 tests) must remain green with zero regressions.
