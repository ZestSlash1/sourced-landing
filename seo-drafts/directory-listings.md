## Long description (for directories with a full-text field)
Sourced mines real complaints — not trend reports or keyword scraping — from
Hacker News, GitHub Issues, StackExchange, Codeberg, Discourse, Mastodon, and
YouTube comments. It embeds and clusters near-duplicate complaints across
sources: when independent people on different platforms are hitting the same
wall, that's a much stronger validation signal than one loud thread.

Each validated cluster becomes an idea drop — a build brief with the raw
evidence linked (not summarized away), a signal count, and a starting point
written to paste directly into Claude Code, Cursor, Windsurf, v0, or Bolt.

Built for solo founders and indie hackers who want a build target backed by
proof someone else already has the problem, not a hunch.

## "Alternative to" framing (for AlternativeTo, SaaSHub comparison fields)
Alternative to: generic AI idea-generator tools (which hallucinate demand)
and manual trend-scraping (Reddit/Twitter scrolling). Sourced's differentiator
is cross-platform evidence — every idea drop links back to the real
complaints it was built from.
