# Tier 5 outreach templates

## Guest post pitch (dev-tool / indie-maker newsletters)

Subject: Guest post idea — how I built an idea-clustering pipeline (with a backlink)

Hi [name],

I read [newsletter] regularly — [one genuine specific reference to a
recent issue]. I'm building Sourced (getsourced.dev), a tool that mines
real complaints from Hacker News, GitHub Issues, and StackExchange and
clusters them across platforms into validated micro-SaaS build briefs.

I'd like to pitch a guest piece: "How I built a pipeline that clusters
real complaints into validated startup ideas" — covering the embedding
similarity approach, a cross-platform clustering bug that returned zero
matches at 370 signals, and the fix. Technical, not a product pitch — happy
to keep the plug to a single line + link at the end.

Word count / format flexible to whatever works for you. Have a draft ready
if you want to see it before committing to a slot.

[Your name]

## Podcast outreach (indie hacker / bootstrapper podcasts)

Subject: Guest pitch — solo-built idea-validation pipeline, real build-log story

Hi [host name],

Big fan of [podcast] — [specific episode reference, genuine]. I'm the solo
builder behind Sourced (getsourced.dev), a tool that clusters real
complaints from HN/GitHub/StackExchange into validated startup briefs.

Would love to come on and talk through the build — the technical bet
(embedding clustering as validation, not another AI idea generator), a
clustering bug that quietly broke the core premise for a while, and the
decision to run the ingest pipeline on local/free infra (Ollama +
self-hosted gateway) instead of a metered API to keep it sustainable solo.

Happy to send screenshots/traction numbers ahead of time if useful for
prep. Available [general availability].

[Your name]

## Notes
- Personalize the bracketed references before sending — generic pitches get ignored/flagged as spam.
- Only send once there's real traction/screenshots to point to (per the checklist's Tier 5 framing).
