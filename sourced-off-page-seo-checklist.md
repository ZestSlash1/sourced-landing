# Sourced — Off-Page SEO Checklist

Goal: backlinks + referral traffic + domain authority, prioritized for a solo operator with limited time. Ordered by effort-to-impact, not alphabetically.

---

## Tier 1 — Do these first (high impact, low effort)

- [ ] **Show HN post** on Hacker News (news.ycombinator.com) — "Show HN: Sourced — validated micro-SaaS ideas sourced from real complaints." Your own poller already ingests HN, so this audience is a near-perfect match. Post Tue–Thu, ~8–10am PT for best visibility window. One shot — don't resubmit if it flops.
- [ ] **Dev.to article** — write a genuine piece (not an ad) like "I built a pipeline that mines Hacker News, Stack Exchange, and GitHub Issues for validated startup ideas" — technical, shows the embedding/clustering approach, links to Sourced at the end. Dev.to has strong domain authority and your tool audience lives there.
- [ ] **Devhunt.org** — Product Hunt-style directory specifically for developer tools. Free submission, dev-tool-specific audience.
- [ ] **BetaList** — submit as a pre-launch/early-stage product. Good for backlink + early signups.
- [ ] **SaaSHub** — submit + claim your listing, add alternatives/comparisons if relevant.

## Tier 2 — Directory submissions (batch these in one sitting)

- [ ] **Product Hunt** — plan an actual launch (don't just submit quietly). Needs prep: good tagline, first comment, gallery images, hunter with following if possible. Biggest single traffic spike available, but only works once — time it for when the site has more idea drops live so first-time visitors see a populated feed.
- [ ] **AlternativeTo** — list Sourced as an alternative/tool in the "startup idea generator" or "market research" category.
- [ ] **Uneed** — indie/SaaS directory, free tier available.
- [ ] **Fazier** — newer startup directory, decent DA.
- [ ] **Turbo0** — free tool directory, quick submission.
- [ ] **StartupBase** — startup directory with categories.
- [ ] **Launching Next** — pre-launch/launched product directory.
- [ ] **Peerlist** (Projects section) — dev-heavy audience, good fit.
- [ ] **Twelve Tools** — free tool listing site.
- [ ] **Microlaunch** — indie maker launch directory.
- [ ] **SideProjectors** — for side-project discovery.

## Tier 3 — AI-tool directories (Sourced uses embeddings/AI clustering — legitimate fit)

- [ ] **There's An AI For That (TAAFT)** — huge traffic directory, category "Business Ideas" or "Startup Tools."
- [ ] **Future Tools** — curated AI tool directory.
- [ ] **AI Tool Guru** / **AI Valley** — smaller but easy free listings, quick wins.

## Tier 4 — Community engagement (traffic + natural backlinks, ongoing not one-time)

- [ ] **Indie Hackers** — create a product page, post a "build in public" milestone story (you have a genuinely interesting technical story: the clustering bug fix, switching to local Ollama + self-hosted OmniRoute). IH rewards authentic build logs over promo posts.
- [ ] **r/SideProject** — share as a project update, not a sales pitch.
- [ ] **r/SaaS** — same approach.
- [ ] **r/indiehackers** (Reddit mirror) — cross-post.
- [ ] **GitHub "awesome-" lists** — search for `awesome-indie`, `awesome-saas`, `awesome-startup-tools` repos and submit a PR adding Sourced. Real backlinks from high-DA GitHub pages, and this audience is literally your target user.
- [ ] **Twitter/X build-in-public thread** — the technical journey (5 poller sources → embedding clustering → 0 cross-platform matches at 370 signals → why) is genuinely interesting content to devs, not just marketing.

## Tier 5 — Longer-term / higher effort

- [ ] **Guest post pitch** to a dev-focused newsletter or blog (e.g. dev-tool newsletters, indie maker newsletters) — offer the "how I built an idea-clustering pipeline" story as a guest piece with a backlink.
- [ ] **Podcast outreach** — indie hacker / bootstrapper podcasts often want guests with a real build story and are easy to pitch cold once you have some traction/screenshots to show.

---

## Notes
- Don't submit everywhere in one day — spread Tier 1–2 over 1–2 weeks so it doesn't look like a bulk directory-spam run to Google.
- Track which directories you've submitted to and their approval status in this file (check boxes as you go) so you don't duplicate effort.
- Once Product Hunt and Show HN are done, they're one-shot — time them deliberately rather than rushing, ideally once the feed has enough published idea drops to not look empty to first-time visitors.
